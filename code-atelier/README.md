# Code Atelier · 北航复试机试真题库

入口：<https://xuaniyan1.github.io/code-atelier/buaa-exams/>

## 当前内容
- 31 道可判题，96 组公开测试数据。
- 支持 C11、C++17、Python 3；在线编译通过 Wandbox API。
- 本轮修正：2017 中位数题第一个测试的原始下标；三叉树路径题样例中公共祖先路径；将 2019 复杂计算器移至待核验区，避免把有冲突的输出格式当作确定题面。
- Huffman 编码保留为明确标注的训练重建版；平局规则和输出约定不宣称为官方逐字题面。
- 题目按来源标注：公开代码重建、回忆版、公开题解重建、训练版。年份或输入输出未核实的题目不开放判题。

## 测评说明
- 测试数据为本站整理和补充的公开用例，不是北航官方隐藏测试。
- 在线提交会把代码和测试输入发送到第三方 Wandbox 编译运行服务；不要提交密码、隐私或密钥。
- 练习代码保存在当前浏览器 localStorage，不会自动云同步。
