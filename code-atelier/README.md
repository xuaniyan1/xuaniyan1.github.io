# Code Atelier · 北航复试机试真题库

入口：<https://xuaniyan1.github.io/code-atelier/buaa-exams/>

## 当前内容
- 56 道已整理题目，全部 56 道开放自动测评，共 257 组测试数据；其中 48 道为原整理题库，新增 1 道有公开完整题面的 2018 夏令营题与 7 道明确标注的 408 拓展训练题。
- 支持 C11、C++17、Python 3；在线编译通过 Wandbox API。
- 算法大类：动态规划 2 题、字符串与解析 12 题、搜索与递归 1 题、数学与数值 11 题、数据结构 6 题、数组与排序 5 题、树与图 7 题、矩阵与模拟 4 题。
- 每道正式题目都配有可运行测试；题面样例会注明来源，所有本站自造测试均标注为训练用例。待核验题目暂不进入正式判题列表。
- 题目按来源标注：公开代码重建、回忆版、公开题解重建、训练版。年份或输入输出未核实的题目不开放判题。

## 本轮 Review 与修复
- 2018 三叉树：将节点选择规则明确为“孩子数降序、深度降序、先序序号升序”；补充较浅但孩子更多、孩子数相同但深度更深、孩子数和深度相同按先序优先三类测试。参考代码原实现的 `cnt >= cntmax && d > dmax` 并不能完整表达字典序规则。
- 2023 手机基站：题目要求同一基站且时间区间重叠，两个条件必须同时满足；区间端点相等算重叠。
- 2024 运动记录：公开题面只规定同类别按总时长升序，没有说明平局次级排序；补充测试不再用未定义的平局顺序判答案。
- 评测流程：编译/运行失败会明确中止，不再把未执行测试误算进总通过率；显示首个输出差异，并为 Wandbox 请求设置超时。
- Wandbox 编译参数修复：`compiler-option-raw` 使用 API 要求的换行分隔参数（标准版本与优化级别分别一行），避免把 `-std=c++17 -O2` 当成一个参数传给 g++。
- 练习体验：增加本地通过进度和状态筛选；切换题目时保留所选语言；切换语言时先保存旧语言代码，再载入新语言代码；评测期间锁定编辑器，避免把旧代码的通过结果误记到新代码上。代码与通过记录按题目、语言保存在当前浏览器；新增首组测试输入一键复制、Ctrl/⌘+Enter 提交全部测试、Ctrl/⌘+Shift+Enter 运行样例；重置代码前二次确认，避免误覆盖。
- 2019 复杂计算器已按公开回忆补成训练版题面；后缀表达式输出格式由本站明确化，标注为重建版本，不冒充官方逐字题面。
- 2025 Huffman 继续标注为训练重建版，不将补充的平局规则和样例冒充官方原题。

## 本轮低覆盖题补测
- 将原先只有 2 组用例的三叉树最短路径补至 6 组，覆盖跨分支、同父节点、单目标、优先级逆序和回根；按原公开代码重新核对了分支路径输出，补回从当前叶子父节点到最近公共祖先的路径段。随后将 9 道仍只有 3 组用例的题目再各补 1 组，正式题库所有题目至少有 4 组测评；部署验证脚本也会强制检查这一底线。
- 将原先只有 3 组用例的旧题补至至少 4 组，并修正 2017 中位数题首个样例的稳定排序位置：重复的中位数应按原始下标取第 3 个元素，而不是第 4 个。
- 新增覆盖包括大整数、空解、降序范围、部分矩阵覆盖、强数、重复变量、Best Fit 平局、目标手机号多日志和分钟转小时等。

## 新增测试覆盖
- 学生成绩排序：成绩主关键字、同分姓名降序、同名同分、单元素。
- 空白字符统计与字符串模式匹配：多行输入、制表符、结束标记、字符类、大小写、长度不等与无匹配。
- 数值计算：Newton 立方根多组输入、泰勒级数的零点/一般值/较大输入、科学计数法的整数/小数/零/前导零/尾随零。
- 五子棋：四个扫描方向、棋盘边界、六连形成的多个五子窗口、空棋盘和多棋手。
- 数论与树图：亲和数/非亲和数/素数、整数反转前导零、LCA 深度差、线段链分叉与并列、三叉树多目标路径及回根。
- 表达式与序列：多字符变量、重复变量、括号、优先级、左结合、浮点除法；数字塔负数/重复值；最大 m 段和的负数、相邻段和 m=n；核酸队伍的嵌套约束、共享端点和无关系。
- 所有新增用例都带有覆盖说明；本站自造数据明确标注为训练用例，不代表官方样例或隐藏测试。
- 新增 `scripts/validate-question-bank.mjs`，在 Pages 部署前检查题目字段、重复 ID、测试数据结构、样例一致性、来源标注及内嵌 JavaScript 语法；验证失败时阻止部署。

## 本地维护
- 题库仍以静态 HTML 中的 `problems` 与 `cases` 两个数据对象维护；编辑后运行 `node scripts/validate-question-bank.mjs`，再提交。
- GitHub Actions 会在部署前自动执行同一验证脚本，避免题库 JSON 或页面脚本错误直接上线。

## 测评说明与限制
- 测试数据为本站整理和补充的公开用例，不是北航官方隐藏测试。
- GitHub Pages 是静态网站，公开测试数据可以被查看；它不是保密的服务端 OJ。
- 在线提交会把代码和测试输入发送到第三方 Wandbox 编译运行服务。服务可能限流、超时或暂时不可用。
- 代码与通过状态保存在当前浏览器的 localStorage，不会云同步；清理浏览器站点数据会清除本地记录。没有完整测试数据的题目可先编写代码，但不会计入已开放测评题的通过进度。
- 原题资料存在回忆版本差异，尤其是年份、空节点标记、平局规则和输出格式。页面优先标出不确定性；明确补充的训练规则会标为重建版，不将推测冒充官方规则。
