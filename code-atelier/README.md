# Code Atelier · 北航复试机试真题库

入口：<https://xuaniyan1.github.io/code-atelier/buaa-exams/>

## 当前内容
- 48 道已整理题目，其中 30 道开放自动测评，共 101 组公开测试数据。
- 支持 C11、C++17、Python 3；在线编译通过 Wandbox API。
- 算法大类：动态规划 2 题、字符串与解析 12 题、搜索与递归 1 题、数学与数值 11 题、数据结构 6 题、数组与排序 5 题、树与图 7 题、矩阵与模拟 4 题。
- 题面与测试数据分开管理：没有测试数据的题目仍可浏览、编写和本地保存代码；样例存在时可单独运行，完整测评数据补齐后再开放提交。
- 题目按来源标注：公开代码重建、回忆版、公开题解重建、训练版。年份或输入输出未核实的题目不开放判题。

## 本轮题库扩充与分类
- 补入 2006 学生成绩排序、2007 空白字符统计、2008 字符类匹配、2009 立方根迭代与文本过滤、2010 余弦级数、2013 科学计数法、2014 五子棋、2015 亲和数、2016 整数反转、2017 二叉树最近公共祖先、2018 线段连接链、2019 三叉树路径访问等参考代码重建题。
- 补入 2019 复杂计算器、数字塔代表数、最大化求和、数据位置、核酸队伍等公开完整题面；新题暂不批量造测试，后续统一生成。
- 每道题增加算法大类和具体标签，支持按年份、大类、知识点、关键词筛选；同一大类下的知识点选项会动态收窄。
- 撤下缺少原题依据的“数组与堆”推测题面，移入待核验区；机场登机口调整模拟也因输出语义未核实暂缓开放。

## 本轮 Review 与修复
- 2018 三叉树：将节点选择规则明确为“孩子数降序、深度降序、先序序号升序”；补充较浅但孩子更多、孩子数相同但深度更深、孩子数和深度相同按先序优先三类测试。参考代码原实现的 `cnt >= cntmax && d > dmax` 并不能完整表达字典序规则。
- 2023 手机基站：题目要求同一基站且时间区间重叠，两个条件必须同时满足；区间端点相等算重叠。
- 2024 运动记录：公开题面只规定同类别按总时长升序，没有说明平局次级排序；补充测试不再用未定义的平局顺序判答案。
- 评测流程：编译/运行失败会明确中止，不再把未执行测试误算进总通过率；显示首个输出差异，并为 Wandbox 请求设置超时。
- 练习体验：增加本地通过进度和状态筛选；切换题目时保留所选语言；切换语言时先保存旧语言代码，再载入新语言代码；评测期间锁定编辑器，避免把旧代码的通过结果误记到新代码上。代码与通过记录按题目、语言保存在当前浏览器；新增样例输入一键复制、Ctrl/⌘+Enter 提交全部测试、Ctrl/⌘+Shift+Enter 运行样例；重置代码前二次确认，避免误覆盖。
- 2019 复杂计算器已按公开回忆补成训练版题面；后缀表达式输出格式由本站明确化，标注为重建版本，不冒充官方逐字题面。
- 2025 Huffman 继续标注为训练重建版，不将补充的平局规则和样例冒充官方原题。

## 测评说明与限制
- 测试数据为本站整理和补充的公开用例，不是北航官方隐藏测试。
- GitHub Pages 是静态网站，公开测试数据可以被查看；它不是保密的服务端 OJ。
- 在线提交会把代码和测试输入发送到第三方 Wandbox 编译运行服务。服务可能限流、超时或暂时不可用。
- 代码与通过状态保存在当前浏览器的 localStorage，不会云同步；清理浏览器站点数据会清除本地记录。没有完整测试数据的题目可先编写代码，但不会计入已开放测评题的通过进度。
- 原题资料存在回忆版本差异，尤其是年份、空节点标记、平局规则和输出格式。页面优先标出不确定性；明确补充的训练规则会标为重建版，不将推测冒充官方规则。
