## MIPS 宏与数组

- `scanfint(%reg)`：syscall 5，结果从 `$v0` 移到传入寄存器。
- `printfint(%reg)`：把数放入 `$a0`，令 `$v0=1`，再 syscall。
- 二维数组字节偏移：`(i * 实际列数 + j) * 4`。
- 每行 8 列：`((i << 3) + j) << 2`。
- 每行补齐到 16 列：`((i << 4) + j) << 2`，不是 `i<<3`。

## 递归与栈

进入当前层时：

```asm
push($ra)      # 保存当前层应该返回到哪里
```

离开当前层时：

```asm
pop($ra)       # 恢复当前层的返回地址
jr   $ra
```

判断某个值要不要 push，只问：

> `jal` 返回后，当前层还需要这个旧值吗？

- GCD 返回后不再使用旧参数：只需保存 `$ra`。
- 阶乘返回后还要使用当前层的 `n`：保存 `$ra` 和 `$a0`。
- 子函数返回值在 `$v0`；不要再用已经被递归修改的 `$a0` 覆盖它。
- push 顺序和 pop 顺序相反。

## 乘法与除法

```asm
mult  $t0, $t1       # 有符号乘法
multu $t0, $t1       # 无符号乘法
mflo  $t2            # 乘积低32位
mfhi  $t3            # 乘积高32位
```

```asm
div  $t0, $t1        # 有符号除法
divu $t0, $t1        # 无符号除法
mflo $t2             # 商
mfhi $t3             # 余数
```

- 两个 `n` 位数相乘，完整结果最多是 `2n` 位。
- 完整乘积拼接顺序：`{高位, 低位}`。
- `HI/LO` 会被下一次乘除法覆盖，需要就尽快读出。
- GCD 使用 `mfhi`，因为下一层需要余数。
- 除数不能为 0。

## Logisim 容易记错的地方

| 容易产生的印象 | 更准确的说法 |
|---|---|
| Negator 是逐位取反 | Negator 是算术取负：`-x = ~x + 1`；NOT 才是逐位取反 |
| carry out 就是所有溢出 | carry out 是无符号进位；有符号溢出要看同号相加是否得到异号 |
| borrow out 是有符号溢出 | borrow out 是无符号借位 |
| DMUX 未选中输出是 X | 开启三态后是高阻态 Z；完全悬空或冲突时才可能观察到 X |
| 给其他寄存器 D 输入 Z/X 就能保持 | 错；保持应使用寄存器 Enable，或让 MUX 选择 `D=Q` |
| D 在周期结束时才写入 | D 是组合逻辑一直在算的下一状态；时钟沿到来时才由寄存器采入 Q |
| 寄存器初始化立即生效 | 通过 D 端同步装载初值，需要等待一个有效时钟沿 |

## 一个周期到底发生什么

```text
时钟沿之前：组合逻辑根据当前Q计算D
时钟沿到来：寄存器采样D
时钟沿之后：Q更新，组合逻辑根据新Q重新计算
```

同步初始化时：

```text
第一个沿：初值进入Q
第一个沿之后：开始计算第一轮next state
第二个沿：第一轮结果进入Q
```

不要只写“T0/T1”，最好同时写清“第几个上升沿之前/之后”。

## 矩阵快速幂电路

状态寄存器：

```text
R：当前答案矩阵
B：当前底数矩阵
N：当前指数
```

初始化：

```text
R = 单位矩阵
B = 基础矩阵
N = 输入指数
```

每轮组合计算：

```text
N最低位为1：nextR = R * B
否则：      nextR = R

nextB = B * B
nextN = N >> 1
```

同一时钟沿同时执行：

```text
R <- nextR
B <- nextB
N <- nextN
```

三个 next 值都由沿之前的旧 `R、B、N` 算出。

## 接线检查

- MUX 不需要 `en` 时，在属性中关闭 Enable 输入。
- `clk` 和 `reset` 分开走线，交叉处检查连接圆点。
- 控制线不要悬空。
- 多路设备共用总线时才考虑三态；寄存器保持用 Enable 或 `D=Q`。
- 调试时按 `Q → 组合逻辑 → D → 时钟沿 → Q` 的顺序查。
