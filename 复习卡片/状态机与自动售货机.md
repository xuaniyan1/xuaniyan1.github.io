## 一句话定义

```text
CState：这一拍已经保存的历史
input：这一拍新来的输入
NState：下一拍要保存的历史
```

```text
所有状态机：NState = f(CState, input)
Moore 输出：output = g(CState)
Mealy 输出：output = g(CState, input)
```

## 5 元售货机，串行投入 2 元或 3 元

- Moore：`S0、S2、S3、S4、S5、S6、S7`。进入 S5/S6/S7 后才出货、找零。
- Mealy：`S0、S2、S3、S4`。够钱的那条转移边直接输出，`NState` 回 S0。
- 状态数字表示处理当前硬币**之前**已经累计的钱。

例：当前已有 2 元，这一拍投入 3 元。

```text
Moore：S2 + 3 -> S5；时钟沿后进入S5并出货
Mealy：S2 + 3 -> S0；这一拍直接vend=1
```

## 同步初始化时间线

```text
第0周期：init把S0送到D
第0周期末的沿：Q变成S0，初始化完成
第1周期：CState=S0，与input1一起计算NState
第1周期末的沿：NState写入Q
```

第 1 周期中：

- Mealy 输出由 `CState + input1` 计算。
- Moore 输出只由 `CState` 计算。

异步 reset 不必等待正常计算时钟；不要和上面的同步初始化混在一起。

## Logisim 三块结构

```text
状态寄存器：保存CState
下一状态逻辑：CState + input -> NState
输出逻辑：Moore接CState；Mealy接CState + input
```

最容易犯的错：拿 `NState` 直接当当前状态。`NState` 还只在 D 端，经过时钟沿成为 `CState` 后才是真正保存下来的状态。
